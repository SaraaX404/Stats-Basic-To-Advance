# Applied Statistics Jupyter Course

41 combined theory-and-lab notebooks across eight subjects. Each topic is explained in our own words, with Markdown theory, LaTeX formulas, assumptions, derivations, worked tables, Python calculations, simulations and exercises. There are 305 theory subsections and 88 worked tables.

## Open the course

Install Python 3.10 or later and the packages in requirements.txt, launch JupyterLab, and open [00_Course_Roadmap.ipynb](00_Course_Roadmap.ipynb).

## Project contents

There is one notes-and-lab file for each topic, plus the course and subject indexes. The images in _images are original course guides. Original PDFs remain outside this course folder; copied lecture notebooks, PDF screenshots and standalone Python helper files have been moved out of the project. Git ignore rules continue to exclude local reference material.

[Theory coverage](THEORY_COVERAGE.md) lists the subtopics in each notebook. [Review record](REVIEW_REPORT.md) describes the teaching changes and validation. The notes are newly written study explanations informed by the supplied materials, not a transcription of every administrative sentence or a collection of lecture-page images.
